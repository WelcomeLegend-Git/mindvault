# Contributing to MindVault

Thank you for your interest in contributing to MindVault! MindVault is an open-source Android application built with modern Kotlin, Jetpack Compose, and Android Jetpack libraries.

## Code of Conduct

All contributors are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

### 1. Reporting Bugs
* Check existing [GitHub Issues](https://github.com/WelcomeLegend-Git/mindvault/issues) before opening a new issue.
* Provide device model, Android version, steps to reproduce, and expected vs actual behavior.

### 2. Suggesting Features
* Open a Feature Request under GitHub Issues describing the user problem and proposed solution.

### 3. Pull Requests (PRs)
1. Fork the repository and create a feature branch: `git checkout -b feature/amazing-feature`.
2. Ensure the code compiles cleanly: `./gradlew compileDebugKotlin` and unit tests pass: `./gradlew test`.
3. Adhere to Kotlin standard coding conventions and Jetpack Compose best practices.
4. Commit your changes with clear, descriptive commit messages.
5. Push to your branch and open a Pull Request against `main`.
